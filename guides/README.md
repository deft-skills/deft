# DEFT documentation

Read in this order the first time:

1. [The DEFT metamodel](metamodel.md): specialization, composition, and why they are
   checked together.
2. [Writing models](modelling-guide.md): artifact types, skills, families and workflows
   in YAML, including reuse of third-party skills.
3. [Validating models](constraints.md): every check `deft check` runs, with typical
   messages, and the review of contracts.
4. [Generating skills](generation.md): what a generated `SKILL.md` contains.
5. [Using generated skills](using-skills.md): installing them in an agent and running a
   workflow; the [account-service example](../examples/account-service/) walks
   through a complete run.
6. [Command line](cli.md): reference of the `deft` command.

The example library under [`models/`](../models/) is the reference for every guide.
