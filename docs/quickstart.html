Get started

Quickstart

Install DEFT, check the example library, and generate its skills.

Install

Requires Python 3.11 or later.

Get the repository from https://anonymous.4open.science/r/deft-F7FE/, then:

cd deft
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[test]"

Check the example library

deft check models
# 14 types, 21 skills: 0 violation(s)

Bind an incompatible variant in models/workflows/deliver-feature.yaml, for instance bind: ears for the functional node, and check again:

[C2] workflow deliver-feature: data edge functional.requirements -> acceptance.requirements:
     EARSRequirement (from ears) does not conform to UserStory (required by acceptance-gherkin)

Generate and inspect skills

deft resolve models volere           # the SKILL.md an agent receives for 'volere'
deft generate models --out skills    # one folder per concrete skill and workflow
deft obligations models              # contracts to review in the workflows
